# mediatidy-rule

MediaTidy 自用规则整理与分享仓库，主要包含分类、命名和单版本收藏评分规则。

规则以实际媒体整理场景为基础进行调整，尽量在保持目录结构简洁的同时，提高分类准确性、命名可读性以及单版本收藏时的资源筛选质量。

## 规则内容

### 分类规则

文件：

`category-rules.yaml`

用于电影、剧集、动漫及演唱会自动分类。

主要特点：

* 固定现有目录结构，不额外增加分类目录
* 结合标题、类型、关键词、合集等信息进行分类
* 地区判断主要使用 `origin_country` 与 `original_language`
* 普通剧集和动漫优先依据来源国家，必要时使用原始语言补充
* 华语电影、日韩电影主要依据原始语言判断
* 包含电影、动漫、电视剧及演唱会保底分类
* 支持按年份进一步划分目录

当前年份范围：

`1550-1999 / 2000-2009 / 2010-2019 / 2020-2029 / 2030-2039 / 无年份`

部分分类路径会存在多条独立规则，用于覆盖不同匹配条件。相同路径不会因此创建额外目录。

---

### 评分规则

文件：

`score-rules.yaml`

用于电影和剧集的单版本收藏及洗版升级。

核心思路是在分辨率、片源和视频码率之间进行综合权衡，降低单纯依靠分辨率判断资源质量带来的影响。

主要特点：

* 加强视频码率权重
* 避免低码率 4K 仅凭分辨率压过高质量 1080p
* 分辨率仍保持较高优先级，但不是绝对条件
* Remux、BluRay、WEB-DL 等片源参与评分
* Dolby Vision、HDR10+、HDR10 等动态范围参与评分
* 高质量正片音轨提供额外加分
* 中文字幕提供小幅加分
* 视频编码格式本身不直接参与评分
* 文件大小、容器、总码率及帧率不参与评分
* 单版本模式，不单独建立 DV / HDR 等版本槽位

需要注意，评分规则基于 MediaTidy 能够识别到的媒体元数据进行综合计算，并不等同于实际画质检测。

不同母版、编码参数、调色、降噪以及压制质量等因素仍可能影响最终实际观感。

---

### 命名规则

文件：

`naming-rules.yaml`

用于电影、剧集目录及媒体文件统一命名。

主要特点：

* 电影和剧集采用统一且易于识别的命名结构
* 目录保留 TMDB 编号
* 剧集季目录使用 `Season 1` 格式
* 剧集文件保留 `S01E01` 与中文集数信息
* 支持片源、版本、动态范围、色深等信息
* 支持音频编码及声道信息
* 命名结果依赖 MediaTidy 实际识别到的媒体元数据

部分变量缺失时，对应命名字段可能为空，最终结果以 MediaTidy 实际解析结果为准。

## 使用方法

下载需要使用的 YAML 文件，并将对应规则导入 MediaTidy。

如果现有配置中已经存在对应顶层字段，请将规则内容合并到原有列表中，不要重复创建相同的顶层键。

建议在正式整理媒体库之前，先使用少量资源测试分类、命名及评分结果。

评分规则用于洗版时，还需要在 MediaTidy 的整理方案中开启对应的洗版升级及元数据提取功能。

## 注意事项

规则效果依赖 MediaTidy、TMDB 以及媒体文件自身元数据的完整性和准确性。

以下情况可能导致分类、命名或评分出现偏差：

* TMDB 元数据缺失或错误
* 合拍及跨国制作内容
* 文件名无法正确识别片源
* HDR / Dolby Vision 信息识别不完整
* 音轨或字幕元数据标记错误
* 不同母版或不同压制版本存在实际画质差异

建议将这些规则作为自动整理依据，而不是对媒体实际质量的绝对判断标准。
